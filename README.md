# 💻 asep
### Διαδραστική εφαρμογή προετοιμασίας για διαγωνισμούς του ΑΣΕΠ

📍 **URL**: [https://asep.fmaths.gr](https://asep.fmaths.gr)  
👤 **Δημιουργός**: Φώτης Χ. Κουτσουμπίδης

---

## 📘 Περιγραφή

Το **asep** αποτελεί μια διαδραστική εφαρμογή προσομοίωσης και εξάσκησης με ερωτήσεις πολλαπλής επιλογής από το **Μητρώο Θεμάτων Γνώσεων** του ΑΣΕΠ, οργανωμένες σε **11 θεματικές ενότητες**.

Ο χρήστης μπορεί να επιλέξει:

- συγκεκριμένες ή όλες τις ενότητες
- συγκεκριμένο πλήθος ερωτήσεων ή όλες τις διαθέσιμες ερωτήσεις
- λειτουργία προσομοίωσης ή εξάσκησης
- επανάληψη ερωτήσεων που απαντήθηκαν λανθασμένα

ℹ️ Η εφαρμογή είναι **ανεπίσημη** και προορίζεται αποκλειστικά για **εκπαιδευτική χρήση**, χωρίς εμπορικό σκοπό.

---

## ⚙️ Τεχνολογίες

- ⚛️ [React 19](https://react.dev/)
- ⚡ [Vite](https://vitejs.dev/) για ανάπτυξη και build
- 🟢 [Node.js](https://nodejs.org/) για npm scripts & περιβάλλον ανάπτυξης
- 🎨 JSX & CSS
- 📄 JSON δεδομένα για τις ερωτήσεις με αυτοματοποιημένο build
- 📊 Google Analytics (`gtag.js`)
- ✅ ESLint με React rules

## 🚀 Εκτέλεση (Development & Build)

Χρήση με **Vite**:

```bash
npm install       # Εγκατάσταση εξαρτήσεων
npm run dev       # Ανάπτυξη με live reload
npm run build     # Παραγωγικό build
npm run preview   # Προεπισκόπηση του build
```

💡 Προϋπόθεση: εγκατεστημένα **Node.js** και **npm**  
🖥 Ο development server είναι προσβάσιμος και από το τοπικό δίκτυο (`host: true`).
